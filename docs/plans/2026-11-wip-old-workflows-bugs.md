## Test suites to add (and order)

1. **Pure Scala/unit**: DSL macro exhaustiveness/field binding; `JsonSchema` strictness, `Ista` tool routing; `Convo` optional-query/serialization; type mapping and mixed `ToolChoice`. Tests must fail meaningfully before the respective fix is considered implemented.
2. **Native workflow fixture**: Build `Convo` and `EventHandler` using current `compiler-rust`, run one human turn and one tool roundtrip, inspect persisted DB messages, completion, tool calls and callback. Simulate last-effect crash; replay must not double-charge or duplicate messages/effects.
3. **Workflow lifecycle**: Enable wrappers one by one. Assert step ordering, single terminal status, lock release, and no parallelized prerequisite effects. Compare against current native Project Manager run as baseline.
4. **Full Project Manager session**: 10–14 read-only sequential file reads, CHECK_TASKS, multiple tool calls, empty/omitted user continuation, nested callback, budget edge cases, concurrent incoming turn, tool errors and retry. Validate status, history, project scoping and usage/cost in PostgreSQL.
5. **Cache regression**: Compare GCS captured OpenAI payloads with replay script; verify append-only-prefix behavior before 17K size limiter, no early historical modification from summaries/collapser, and repeatable compaction behavior. Current documented reference: 100K run ~83.9% cached vs 17K ~56.8% in distinct real runs; use comparable fixtures, not those figures as fixed acceptance thresholds.
6. **Feature toggle / rollout**: First baseline then typed tools then `Convo` then lifecycle traits. Gate release on no failures; rollback by switching back to old workflow build, not reverting server infrastructure.
